# Thursday Show & Tell — Trace, test, defend

Prepare one compact algorithm evidence artifact from class: a pseudocode
trace, a test table containing an edge case, and either a correctness invariant
or a counterexample and repair. It may be handwritten; programming is not
required.

In a small audience:

1. State the procedure's input/output contract.
2. Show the edge case that most strongly tests the claim.
3. Defend one invariant, test result, or repair.
4. State what your tests cannot establish about all inputs or growth.

Give a peer one professional critique about a contract, edge case, invariant,
or operation count. Revise if warranted. Submit the individual report using
`assignments/show-and-tell-artifact.md`; it records the public reasoning and
critique, not a duplicate of your technical artifact.
