# Thursday Pair Reasoning — Compare representations

Work with a partner after each of you records an individual starting position.
Compare two ways to represent a small scenario supplied in class: a set, a
function table, a sequence, or another precise representation.

Together, make one inspectable artifact: a mapping table or sequence trace
with labeled domain/codomain, plus a short note identifying one distinction
the representation preserves and one it omits. Test one boundary case.

Do not divide the task into roles. Instead, challenge each other's
definitions: Does every input have exactly one output? Did the codomain move?
Does the sequence rule really generate the listed terms?

Each partner submits an individual report using
`assignments/pair-reasoning-report.md`. Reference the shared artifact, but do
not submit a duplicate copy as the report.
