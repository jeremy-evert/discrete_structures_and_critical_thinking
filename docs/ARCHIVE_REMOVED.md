# Where did `archive/` go?

Old Canvas course snapshots (Fall/Spring 2021-2026), a publisher cover image and a link to a
student's work were removed from this public repository, and from its history, on 2026-11-11.

Why: a public repository should hold only material we are free to publish. The snapshots
came from Canvas, which is the permanent home for course content, and some of it was not ours to redistribute.

If you cloned this repo before that date, your copy still has the old history. To get a clean
copy, delete it and clone again. Do not push old branches back.

The `archive/` folder is now in `.gitignore`, so a private local copy cannot be committed by accident.
