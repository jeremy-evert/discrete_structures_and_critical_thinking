# Week 14 recap outline

## Tuesday — five things we taught

- A Boolean variable holds `True` or `False`, and an assignment gives every
  variable a value.
- A truth table lists the results for every assignment. A counterexample is
  one assignment that disproves a claim that two expressions are equivalent
  (give the same result in every case).
- A gate performs one operation; a circuit connects gates to represent an
  expression. Check each truth-table row against the written expression.
- A satisfying witness is one assignment that makes an expression true; a
  tautology is true for every assignment. Checking every assignment is a
  universal proof for this finite set of cases; one witness is not.
- A finite-state machine is a model with named states and rules for how inputs
  change them. A trace lists those states and inputs in order. Model limits
  are facts the model leaves out and therefore cannot establish.

## Thursday — five things we taught

- A defensible model begins with named states or variables, allowed inputs,
  rules, and assumptions.
- A complete truth table or two explicit traces (ordered state/input runs)
  turns a claim into evidence a
  peer can inspect.
- A transition says which state follows a state and input. A challenge is
  useful when it tests a row, input, transition, or unstated
  assumption rather than attacking a person.
- A model limit names what the chosen representation cannot establish, such as
  authorization or an unlisted state.
- Revision is part of reasoning: the strongest final claim is the one the
  surviving evidence actually supports, with its boundary stated.
