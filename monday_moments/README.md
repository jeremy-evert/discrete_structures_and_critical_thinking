# Monday Moments — Discrete Structures and Critical Thinking

A short, weekly tip-of-the-week for working with AI, scoped to logic, proofs, sets, and formal reasoning.

**Engagement level for this course: critically auditing AI's own reasoning.**

This is the course where AI is least trustworthy and most useful as a *subject of study*, not just a tool. LLMs frequently produce fluent-sounding proofs that are subtly invalid — wrong quantifier order, an unproven inductive step, a hidden circular argument. That's exactly the material of this course, so the moments here flip the usual script:
- Give the AI a proof to check; find the gap yourself before trusting its verdict.
- Ask it to prove something false and see how convincingly it can be wrong.
- Use it to explore truth tables or set identities quickly, then verify by hand — speed is fine, trust is not.
- Practice naming *which* logical rule an AI's argument actually violates, not just "that feels off."
