# Weekly Problem-Solving Rubric Template

| Criterion | Full-credit evidence |
|---|---|
| Sources | Relevant references are identified and used honestly. |
| Rules / assumptions | Definitions, constraints, and modeling choices are stated. |
| Work | Reasoning, calculations, code, or diagrams are complete enough to follow. |
| Check | Result is tested, cross-checked, or interpreted for plausibility. |
| Summary | One sentence accurately states the result and method. |

The five-part structure is repeated explicitly in spring 2026 and described in 2021 homework/exam text. Set points per section for the current offering.
