# Thursday activity — Container boundaries and repeatability

Follow the six-section order in the shared Container Connections evidence
manifest. Work in pairs, but each student submits their own reflection and
must be able to explain the evidence.

1. Map the layers and record the prepared preflight state.
2. Observe process exit, inspect the retained container, remove it, and
   distinguish the surviving image.
3. Prove a named volume survives writer removal and is readable by a different
   read-only container.
4. Contrast the named volume with the approved Windows host bind.
5. Run the exact deterministic workload twice and compare byte length and
   SHA-256, not displayed text alone.
6. Analyze the supplied Bill/Brandy packet and state one bounded portability
   claim plus one limitation.

Capture the six required receipts from the shared manifest. Do not use Docker,
change security policy, create a machine, prune runtime state, delete an
unverified path, or log into Brandy.
