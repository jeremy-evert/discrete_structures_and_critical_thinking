# DSCT Tuesday Evidence and Reflection

This is a thin DSCT wrapper. The canonical submission filename, shared questions, readiness fields, privacy review, and assignment instructions remain in `local_ai_lab_setup/curriculum/shared/week2/12_readiness_assignment.md`. Add the following under its `### Course-specific reflection` heading in `local-ai-readiness.md`.

## Evidence source label

Choose one and keep it accurate:

- `MY MACHINE — READY`: I ran the source-backed workflow on my supplied exercise.
- `MY MACHINE — NOT READY`: I recorded the accurate status/code and used the support path.
- `SUPPLIED DEMONSTRATION EVIDENCE`: I used an instructor/partner receipt because my machine was not ready or was not used for this step.

## Four-part reflection

### claim

State the narrow claim about `format_student_name` that the supplied exercise asks you to inspect.

### counterexample/baseline observation

Record what `Baseline` actually showed, or identify the supplied evidence source. Explain how the observed input/output challenges or fails to support the claim.

### what the diff changes

Describe the actual file and expression changed. The expected DSCT extension is `student_code.py` only, with `.upper()` changed to `.title()`; report a different result honestly.

### limit

Explain what the passing `Final` test supports and what it leaves unproven. State why Aider completing the request is a proposal event, not evidence that the claim follows.

## One-sentence summary

Write one sentence using the Week 1 method: conclusion + strongest evidence + remaining limit.
