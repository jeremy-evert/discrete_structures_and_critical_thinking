# Tuesday activity — A claim about a prepared AI lab

Use the shared local-AI module and the DSCT extension. This is the in-class
evidence organizer; the graded submission is the single
`local-ai-readiness.md` file described in `week-02-evidence-assignment.md`.

## Evidence card

- **Claim:** What did I want to know about the local-AI lab or bounded change?
- **Sources:** Which shared page, checker result, diff, or test did I use?
- **Rules / Assumptions:** What was supplied, bounded, or not allowed?
- **Work:** What did I run or inspect? Record only privacy-safe facts.
- **Check:** What observation challenged or supported the claim?
- **One-Sentence Summary:** What does the evidence establish, and what does it
  not establish?

## Pair review

Ask your partner to identify one unsupported jump and one missing observation.
If the readiness check is `NOT READY`, do not repair the machine: retain the
diagnostic code and explain what that result does and does not establish.
