# Recap outline (for the post-class recap)

## Tuesday, November 3 (class cancelled; this is the content that was planned)
- A distance table with different costs each way is a directed, weighted graph; 1→2 can differ from 2→1.
- A tour's length is the sum of every leg including the return leg (1-2-3-4-5-6-1 totals 55; the reverse totals 56).
- Greedy (nearest unvisited city) gives 39 here, but the best tour is 34: greedy is fooled.
- Guess and check keeps a best-so-far that only drops, but never knows it has the best.
- Brute force finds the best (34 over 120 tours); n cities give (n-1)! tours, so 15 cities is about 87 billion.
