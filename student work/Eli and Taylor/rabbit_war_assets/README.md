# Rabbit War reference images

Reference-image assets for `rabbit_war.py`.

- Target format: 1024×1024 RGB JPEG.
- Stable filenames and metadata live in `manifest.json`.
- Run `python fetch_and_standardize.py` from this folder to materialize remote-backed images.
- Images are historical/reference material; a reference image is not necessarily official regime propaganda.
- `khmer_rouge.jpg` is Khmer Rouge propaganda and must not be mislabeled as a Pol Pot portrait.

The student work in this repository is a shared learning resource; peers may see it.
