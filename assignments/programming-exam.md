# Reusable Template: Programming Exam

**Historical basis:** six 2021–22 exams. Representative prompts generated sequences, made change, counted primes, compared Fibonacci implementations, enumerated donut choices, and simulated birthday probabilities.

Give a focused computational problem tied to the current unit. Require: (1) a running program, (2) representative outputs/tests including edge cases, and (3) an explanation of the method, assumptions, and interpretation. Optional bonus or reflection may be retained, but set a current point policy.
