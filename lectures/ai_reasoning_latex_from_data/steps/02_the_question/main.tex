\section{The question}
\textbf{Claim:} Increasing the number of simultaneous requests should increase aggregate AI throughput until the available parallelism is saturated. This matters because a plausible explanation such as “the bigger GPU is faster” can confuse hardware capacity with scheduling or measurement overhead.
