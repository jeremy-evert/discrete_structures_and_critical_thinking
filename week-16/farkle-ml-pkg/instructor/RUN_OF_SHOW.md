# Week 16 Run of Show

Two 75-minute meetings. Use the student handout and slides for Tuesday; use `student/thursday_activity.md` and the unchanged evidence receipt for Thursday.

## Tuesday — make a claim, then try to break it

| Time | Move | Instructor action | Student check |
|---:|---|---|---|
| 0–8 | Convincing wrong answer | Show “A won 53 of 100, so A is clearly better.” Ask what would make it wrong. | Name one missing rule, denominator, sample, or scope check. |
| 8–18 | Judgment bridge | Ask what students want to know before accepting one clean workplace metric. Keep this short. | State one question that makes a recommendation inspectable. |
| 18–35 | Make the machine inspectable | Use the slides to show fixed rules, labels, raw fields, balanced starts, and seed identity. Open the initial row only after predictions. | Identify A/B labels, games, starts, wins, ties, and each rate denominator. |
| 35–62 | Reasoning challenge | Students complete the handout's fixed comparison, criterion, prediction, and initial-sample work. Circulate for visible predictions. | Write a decision rule and a bounded initial interpretation. |
| 62–75 | Exit trace | Collect the Tuesday sentence: “In this sample, under these assumptions, ___, but I am not yet willing to claim ___ because ___.” | Leave one unresolved question for Thursday. |

### Tuesday fallback move

If the runner is unavailable, use the prepared initial row in the slides/handout. Do not diagnose installations during class. The learning target is the reasoning trail, not successful local execution.

## Thursday — defend, revise, or refuse

| Time | Move | Instructor action | Student check |
|---:|---|---|---|
| 0–10 | Retrieve the prediction | Have students reopen Tuesday's rule before seeing the bundle. Ask whether they are grading evidence by whether it agrees with them. | Copy the original criterion and threshold/rule. |
| 10–25 | Bundle evidence | Show per-seed rows first: 17, 6262, 2026. Keep the supplied raw counts visible, then ask for ordering, minimum, maximum, and range. | Find −40, +20, +60 pp; range 100 pp; ordering changes. |
| 25–48 | Reorder and limit | Ask whether an alternate metric changes priorities and what the model cannot represent. Avoid turning mean/min/max/range into formal statistical proof. | Test the student's predeclared rule and write one model limitation. |
| 48–60 | AI/confident interpretation audit | Use the prepared overclaim in the Thursday page, or a live AI interpretation only when appropriate. Prompt checks for denominator, criterion, one-sample proof, sign change, and model limit. | Mark at least two defects and write one repaired sentence. |
| 60–70 | Peer critique and final move | Pair students. Each classmate asks one question intended to break the claim. Students choose defend, revise, or refuse. | Record the critique question, answer, and final move in Check Your Answer. |
| 70–75 | Receipt exit | Remind students to submit the unchanged five-heading receipt: Sources; Rules / Assumptions; Work; Check Your Answer; One-Sentence Summary. | Submit the peer-visible graded discussion artifact. |

### Thursday fallback moves

- If live bundle execution fails: open `../fallback/quick_v1_results.csv` or the matching table in the Thursday page; keep the same three rows and continue.
- If students average away the reversal: return to the row-by-row A−B values and ask which row would be hidden.
- If students call a tie or sign change a failure: ask whether their decision rule permits refusal; refusal is a valid evidence-bounded move.
- If students choose an alternate metric after seeing the result: ask when they declared it and whether its denominator is visible.
- If the AI audit becomes a tool debate: return to the claim, counts, denominator, criterion, scope, and model limit.
