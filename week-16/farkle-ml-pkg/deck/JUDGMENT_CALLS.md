# Judgment calls

## AI failure mode used in the Tuesday deck

The topic map did not contain a Week 16 row. For this slice, the judgment call
was to use the course-specific failure mode identified by the coordinator:

> AI (or a confident reader) reports a simulation/ML win and hides the
> denominator or the ordering criterion; a polished interpretation treats one
> sample as proof.

The deck uses that failure mode in the overclaim-audit slide and in prompt 04.
The repair task asks students to expose the denominator, define “best,” narrow
the scope, and name a model limitation. It does not ask students to build an
engine or an ML algorithm.
