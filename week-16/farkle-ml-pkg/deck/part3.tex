\begin{frame}[shrink=18]{A polished interpretation can still overclaim}
\princ{AUDIT THE ARGUMENT}
\begin{alertblock}{Confident reader / AI claim}
The learner won more games in the simulation, so it is clearly the best Farkle strategy. The result proves that machine learning beats the hand-written rule.
\end{alertblock}
\begin{itemize}
\item Hidden denominator: which games and which starts were counted?
\item Missing ordering criterion: what does ``best'' mean?
\item Overreach: one sample becomes a universal claim.
\item Missing model limit: this learner and this opponent are not all possible games.
\end{itemize}
\promptbox{04}{a}
\note{Read the claim as an argument to audit, not an answer key. Question: which phrase should trigger the fastest check? Expected: ``clearly the best'' or ``proves.''}
\end{frame}
