Trustworthy reasoning needs a trustworthy, inspectable setup.}

\begin{frame}{Read the real path}
\begin{enumerate}\item Open the Canvas module.\item Read the setup script.\item Inspect the downloaded file and its location.\item Run the supported command for your operating system.\end{enumerate}
\end{frame}
\begin{frame}{Windows and macOS}
\begin{columns}\column{.48\textwidth}\textbf{Windows}\begin{itemize}\item PowerShell\item `cd` to Downloads\item `ls` and tab completion\end{itemize}\column{.48\textwidth}\textbf{macOS}\begin{itemize}\item Terminal\item documented `uname` checks\item Python/Homebrew checks\end{itemize}\end{columns}
\end{frame}
\begin{frame}{Evidence, not theater}
Keep a small receipt:\\[.5em]
\textbf{Expected} — what should happen?\\
\textbf{Actual} — what did the machine say?\\
\textbf{Tried} — what did you already change or check?
\end{frame}
\begin{frame}{What to carry forward}
\begin{itemize}\item Setup output is evidence about this environment.\item Pair work helps, but preserve your own trail.\item A failure is a useful boundary when recorded precisely.\item Next: use the working environment for containers and repeatability.\end{itemize}
\end{frame}
