# Discrete Structures — Aug. 27 setup recap

## Big idea

Repeatable reasoning needs a repeatable environment: read the course instructions, inspect what you downloaded, run the smallest supported command, and preserve the result.

## Remember

1. Open the actual Canvas module/script, not only the recording.
2. A downloaded file is not automatically trustworthy; know what it is before running it.
3. Windows students can use PowerShell; macOS students can use Terminal and the documented `uname`/Python checks.
4. Use tab completion and `ls`/directory inspection to confirm paths.
5. The Local AI Lab Setup workflow checks tools such as Python and Homebrew where applicable.
6. A successful setup report is evidence that this environment works, not a claim about every computer.
7. Work in pairs when asked, but keep your own evidence and reasoning.

## Recovery path

From Canvas, open the current setup script in the module. Inspect its download location. On Windows open PowerShell in that directory; on macOS open Terminal and follow the Mac-specific commands. Run the checks, save the report, and record **Expected / Actual / Tried** for any failure. Read the Week 2 and Week 3 source paths after setup.

## Exact next action

Run the current Local AI Lab Setup/readiness path on your own machine and save the completed report or a precise failure receipt. Do not submit credentials, raw chat, or student-identifying material.
