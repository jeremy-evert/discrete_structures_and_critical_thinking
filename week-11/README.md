# Week 11 — Relations, Equivalence, Partial Orders, Matrices & Digraphs

**Tuesday, October 27 and Thursday, October 29, 2026** · COMSC-2043-1420

## Purpose and targets

When are two things “the same,” and what properties does the model satisfy?
Represent relations as ordered pairs, matrices, and digraphs; classify
reflexive, symmetric, antisymmetric, and transitive behavior; distinguish
equivalence relations from partial orders. Use **Sources → Rules/Assumptions
→ Work → Check → One-Sentence Summary**.

## Meetings and evidence

- Tuesday: classify a relation and find a concrete witness or violation.
- Thursday: Pair Reasoning using a relation classifier, matrix, or digraph;
  submit the individual reusable [Pair Reasoning report](../assignments/pair-reasoning-report.md).
- Submit [Reasoning Odyssey Checkpoint 2](student/odyssey-checkpoint-2.md).
  It replaces the ordinary Decision Gate this week; do not submit both.

A carried system may supply entities, but it is optional and never replaces a
formal relation definition. No external resource is required.
